# MVP仕様書: ホールデム図鑑

## 目的

テキサスホールデムを始めたばかりの人が、日本語・英語・略語から用語を探し、意味・会話例・関連語まで読める図鑑を作る。

## 参考にした構成

[麻雀図鑑](https://github.com/sutonomega/mahjong-zukan) の考え方を参考に、学習の入口、用語カード一覧、検索と複数の絞り込み、用語詳細、覚えた状態の記録を用意する。色やカード図柄はホールデム向けに構成する。

## 想定利用者

- 配信や記事で見かけたポーカー用語を調べたい初心者
- 英語表記や略語と日本語の意味をつなげて覚えたい人

## 機能要件

1. ホームに学習進捗と「カードの強さ」「役」「ゲームの流れ」「アクション」の4ステップを表示し、それぞれ対応する図鑑へ移動できる。
2. 図鑑を「用語」「役」「カードの強さ」の3種類に切り替える。
3. 用語は日本語名、読み、英語名、別名、説明文から検索する。
4. 用語を「基本」「実戦」の難易度目安、カテゴリで絞り込む。
5. 標準的な10種類の役を強い順に並べ、構成カード例、説明、上回る役・下回る役を表示する。
6. Aから2までのカードランク、スートに強弱がないこと、Aを低く使うストレート、キッカー比較の基本を説明する。
7. 用語詳細に意味、使用例、カテゴリ、関連語、参照資料名を表示する。
8. 「覚えた」状態をブラウザー内に保存し、進捗を表示する。
9. 用語詳細から関連語へ移動し、元の説明へ戻れる。
10. PCとスマートフォン双方で使え、キーボードフォーカスを見えるようにする。

## データ設計

`src/data/entries.ts` に用語を、`src/data/hands.ts` に役とカードランクを登録する。意味の説明は独自の日本語で書き、出典の原文を転載しない。役の強さは標準的なハイハンドの順位を採用し、カードのスートに強弱を設けない。賭け方や利益を勧めるサイトにはしない。

## 技術構成

React + TypeScript + Vite の静的サイト。GitHub ActionsでGitHub Pages向けビルドとデプロイを行う。ユーザー登録やサーバー保存は初期版の対象外で、学習記録はlocalStorageに保持する。

## MVPに含めないもの

ログイン、投稿・コメント、戦略助言、リアルマネー機能、広告、ランキング。

## 受け入れ条件

- 用語名、英語、別名で検索できる。
- 10種類の役が強い順で表示される。
- カードランク、スートの同格、Aを低く使う例を確認できる。
- 難易度とカテゴリを組み合わせて絞り込める。
- 用語詳細と関連語を往復できる。
- 学習済み状態を再読み込み後も表示できる。
- GitHub Actionsで本番ビルドできる。

## 初期版の確認事項

- 初期用語は `src/data/entries.ts` に登録した30語前後。
- 「基本」「実戦」は学習の目安であり、公式な区分ではない。
- ベッティングルールやスラングはゲーム形式・地域で用法が変わるため、出典を併記し、断定表現を避ける。

# MVP仕様書: ホールデム図鑑

## 目的

テキサスホールデムを始めたばかりの人が、日本語・英語・略語から用語を探し、意味・会話例・関連語まで読める図鑑を作る。

## 参考にした構成

[麻雀図鑑](https://github.com/sutonomega/mahjong-zukan) の考え方を参考に、学習の入口、用語カード一覧、検索と複数の絞り込み、用語詳細、覚えた状態の記録を用意する。色やカード図柄はホールデム向けに構成する。

## 想定利用者

- 配信や記事で見かけたポーカー用語を調べたい初心者
- 英語表記や略語と日本語の意味をつなげて覚えたい人

## 機能要件

1. ホームに学習進捗、4つの学習ステップ、用語一覧を表示する。
2. 日本語名、読み、英語名、別名、説明文から検索する。
3. 「基本」「実戦」の難易度目安、用語カテゴリの両方で絞り込む。
4. 一致する用語、名前が似ている用語、説明に含まれる用語を分けて検索結果を見せる。
5. 用語詳細に意味、使用例、カテゴリ、関連語、参照資料名を表示する。
6. 「覚えた」状態をブラウザー内に保存し、進捗を表示する。
7. 用語詳細から関連語へ移動し、元の説明へ戻れる。
8. PCとスマートフォン双方で使え、キーボードフォーカスを見えるようにする。

## データ設計

`src/data/entries.ts` に `id`, `name`, `reading`, `english`, `aliases`, `category`, `level`, `explanation`, `example`, `related`, `source` を持つ用語を登録する。意味の説明は独自の日本語で書き、出典の原文を転載しない。賭け方や利益を勧めるサイトにはしない。

## 技術構成

React + TypeScript + Vite の静的サイト。GitHub ActionsでGitHub Pages向けビルドとデプロイを行う。ユーザー登録やサーバー保存は初期版の対象外で、学習記録はlocalStorageに保持する。

## MVPに含めないもの

ログイン、投稿・コメント、戦略助言、リアルマネー機能、広告、ランキング。

## 受け入れ条件

- 用語名、英語、別名で検索できる。
- 難易度とカテゴリを組み合わせて絞り込める。
- 用語詳細と関連語を往復できる。
- 学習済み状態を再読み込み後も表示できる。
- GitHub Actionsで本番ビルドできる。

## 初期版の確認事項

- 初期用語は `src/data/entries.ts` に登録した30語前後。
- 「基本」「実戦」は学習の目安であり、公式な区分ではない。
- ベッティングルールやスラングはゲーム形式・地域で用法が変わるため、出典を併記し、断定表現を避ける。

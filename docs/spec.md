# MVP仕様書: ホールデム図鑑

## 目的

テキサスホールデムを始めたばかりの人が、日本語・英語・略語から用語を探し、意味・会話例・関連語まで読める図鑑を作る。

## 参考にした構成

[麻雀図鑑](https://github.com/sutonomega/mahjong-zukan) の考え方を参考に、学習の入口、用語カード一覧、検索と複数の絞り込み、用語詳細、覚えた状態の記録を用意する。色やカード図柄はホールデム向けに構成する。

## 想定利用者

- 配信や記事で見かけたポーカー用語を調べたい初心者
- 英語表記や略語と日本語の意味をつなげて覚えたい人

## 機能要件

1. ホームに初級編・中級編・上級編の3コースを表示し、各コースに4つの学習ステップを置く。
2. 各ステップから対応する用語群、役一覧、カードの強さへ移動できる。登録済み用語を3コースで網羅する。
3. 図鑑を「用語」「役」「カードの強さ」の3種類に切り替える。
4. 用語は日本語名、読み、英語名、別名、説明文から検索する。
5. 用語を初級・中級・上級の学習タグとカテゴリで絞り込む。各用語の学習タグは1つだけ付与し、カテゴリは複数の用語に共通して付与できる。
6. 標準的な10種類の役を強い順に並べ、構成カード例、説明、上回る役・下回る役を表示する。
7. Aから2までのカードランク、スートに強弱がないこと、Aを低く使うストレート、キッカー比較の基本を説明する。
8. 上級編ではプリフロップ、フロップ、ドロー、ターン・リバーの定跡の土台を扱う。万能な固定手順ではなく、状況に応じて調整する考え方を明記する。
9. 用語詳細に意味、使用例、カテゴリ、関連語、参照資料名を表示する。
10. 説明文中の登録済み用語を識別し、マウスオーバーまたはキーボードフォーカスで短い説明を吹き出し表示する。
11. 「覚えた」状態をブラウザー内に保存し、進捗を表示する。
12. 用語詳細から関連語へ移動し、元の説明へ戻れる。
13. PCとスマートフォン双方で使え、キーボードフォーカスでも吹き出しを開けるようにする。

## データ設計

`src/data/entries.ts` に用語を、`src/data/hands.ts` に役とカードランクを、`src/data/learningTracks.ts` に段階別コースと用語の割り当てを登録する。説明文中の用語はその辞書データから吹き出し表示する。意味の説明は独自の日本語で書き、出典の原文を転載しない。役の強さは標準的なハイハンドの順位を採用し、カードのスートに強弱を設けない。賭け方や利益を勧めるサイトにはしない。

## 技術構成

React + TypeScript + Vite の静的サイト。GitHub ActionsでGitHub Pages向けビルドとデプロイを行う。ユーザー登録やサーバー保存は初期版の対象外で、学習記録はlocalStorageに保持する。

## MVPに含めないもの

ログイン、投稿・コメント、戦略助言、リアルマネー機能、広告、ランキング。

## 受け入れ条件

- 用語名、英語、別名で検索できる。
- 10種類の役が強い順で表示される。
- カードランク、スートの同格、Aを低く使う例を確認できる。
- 登録済みの全用語が初級編・中級編・上級編のいずれかに含まれる。
- 難易度とカテゴリを組み合わせて絞り込める。
- 用語詳細と関連語を往復できる。
- 学習済み状態を再読み込み後も表示できる。
- GitHub Actionsで本番ビルドできる。

## 初期版の確認事項

- 初期版の用語数は `src/data/entries.ts` の登録内容に合わせて随時更新する。
- 「初級」「中級」「上級」は学習の目安であり、各用語にはいずれか1つを付与する。カテゴリは複数の用語で共有できる。
- ベッティングルールやスラングはゲーム形式・地域で用法が変わるため、出典を併記し、断定表現を避ける。

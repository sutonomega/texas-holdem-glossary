# MVP仕様書: Texas Hold'em Glossary

## 1. 目的

ポーカー初心者が、テキサスホールデムの用語を日本語・英語・略語のどれからでも調べ、短時間で意味と使用例を理解できるWeb辞書を提供する。

## 2. 対象ユーザー

- 配信・記事・会話に出てくる用語を調べたい初心者
- 日本語訳と英語表記を対応づけたい学習者

## 3. MVPの機能要件

1. トップページに用語一覧を表示する。
2. 入力に応じて日本語名、英語名、別名、略語、定義を検索する。
3. カテゴリ（進行・アクション、役・カード、ポジション、ポット・ベット、戦略・略語）で絞り込む。
4. 用語カードに日本語名、英語名、カテゴリ、短い定義、使用例を表示する。
5. 関連語を表示する（初期版では同一ページ内アンカーまたは候補一覧）。
6. 0件の場合は検索語を残し、見つからない旨を表示する。
7. モバイル幅でも検索・閲覧でき、キーボード操作と十分なコントラストに配慮する。

## 4. 用語データ

各項目は `id`, `termJa`, `termEn`, `aliases`, `category`, `definition`, `example`, `related`, `sources`, `reviewedAt` を持つ。MVPでは静的データで開始し、用語の正確性を確認してからCMS/API化する。

## 5. 非機能要件

- 日本語を主言語とし、用語の英語表記を併記する。
- 追加のバックエンドなしで静的ホスティングできる構成にする。
- ページの目的と出典を明記し、既存辞書から定義を転載しない。
- 基本操作をマウスなしで完了できる。

## 6. MVP対象外

ログイン、編集投稿、コメント、戦略助言、リアルマネー機能、広告・アフィリエイト、用語ランキング。

## 7. 受け入れ条件

- キーワードを入力すると一致する用語に絞られる。
- カテゴリ変更と検索を併用できる。
- 用語がない場合に空状態が表示される。
- 主要用語の内容に出典・確認日が紐づく。
- PCとスマートフォンで読みやすく利用できる。

## 8. 次の段階

1. 初期用語30〜50件の定義をレビュー。
2. GitHub Pages等で公開できるリポジトリに配置。
3. ブラウザで画面・検索・モバイル表示を確認。
4. 利用者の検索語や要望を見て、用語提案・CMS化の必要性を判断。
